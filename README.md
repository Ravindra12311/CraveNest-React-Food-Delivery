# 🍔 CraveNest – Food Delivery Website

CraveNest is a responsive food delivery website built with **React** and **Vite**. Users can browse food items, add them to a cart, and place an order.

> **Status:** Frontend complete. Backend is planned (see Roadmap).

## ✨ Features

- Browse food items and menu
- Add and remove items from the cart
- Cart total calculation
- Responsive design for desktop and mobile
- Reusable React components

## 🚀 Getting Started

**Requirements:** Node.js (LTS) and npm

```bash
# 1. Clone the repository
git clone https://github.com/Ravindra12311/CraveNest-React-Food-Delivery.git

# 2. Go to the project folder
cd CraveNest-React-Food-Delivery

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open the link shown in the terminal (usually `http://localhost:5173`).
